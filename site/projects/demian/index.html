project / recurrent substrate

DEMIAN

A recurrent-machine research line built to make internal state explicit enough that continuation, route modulation, and mechanism claims can be tested instead of guessed.

current orientation

How much of a recurrent machine’s future is carried by internal state that is not visible at the surface, and how can that dependence be tested without smuggling stronger claims into the result?

claim boundary

The public runtime supports claims about implementation, state continuity, serialization/restore behavior, ablations, and measurable route modulation.

It does not establish self-awareness, agency, identity, consciousness, self-preservation, homeostasis, or general autonomy. Read the canonical public boundary ↗
runtime anatomy

Six state owners, one continuation problem.

The names are machine-observable roles, not claims that the channels correspond to human cognitive faculties.
